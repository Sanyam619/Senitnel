The lattice fluid campaign under /app advances bundled cases with mid-run snapshots and multi-worker domain splits. Resumed campaigns exit zero and stay finite, but bulk fluid observables disagree with uninterrupted cold starts under the same physics config. Changing the worker count shifts those observables further even when the config is unchanged.

Drive /app/scripts/run_campaign.sh so every case under /app/data/cases/ produces agreeing macroscopic quantities across cold vs resume and across worker counts 1, 2, and 4. Write /output/campaign-report.json with schema_tag set to lbm-campaign-v1, plus cases and parity as documented in /app/docs/report-schema.md. Each cases row needs label, workers, mode, mean_rho, mom_x, mom_y, ke, mass, and stable (each row's math values must be finite). parity must carry cold_resume_max_rel and worker_spread_max_rel. Per-cell bit identity is not required; macroscopic agreement and mass closure are. Rebuild the campaign binary after source edits if you change Go packages under /app.

The verifier regenerates /output/campaign-report.json by invoking a fresh build of /app/cmd/campaign against the current /app sources before running the checks, so any pre-existing report file is discarded and only reports produced by the just-built binary are graded. Beyond the numerical agreement bands, the verifier also invokes the current internal packages directly with its own inputs to check configuration selection, snapshot round trips (including halo handling), and interior-only worker-independent reductions, so replacing the campaign driver or the report emitter with fixed values cannot pass.

When the run manifests under /app/config/manifests/ and any compile-time defaults elsewhere in the source (for example under /app/internal/buildmeta) declare different values for the same knob, treat the manifest as the source of truth for the observables your report emits. Consult /app/docs/report-schema.md for the exact numeric guarantees your report must satisfy, including any physical bounds enforced beyond the agreement bands.
