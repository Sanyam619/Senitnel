The command-line emitter uses these JSON member names for its two artifacts: id, name, instant, status, chain, reason, and queries. The bundled request manifest is /app/data/queries.tsv, and its stable request ids are q01, q02, q03, q04, q05, q06, q07, q08, q09, and q10. Invalid rows with no usable route at the capture instant use reason no_path. Invalid rows whose only convincing proof route depends on withdrawn material use reason replayed and also appear in the replay report. Valid rows carry the label from the chosen proof mark in reason. This note describes public wire labels and fixture identities used by downstream dashboards, not the acceptance rules for any capture.
