# Overnight printer

`/app/kiosk/emit_card.sh` reprints a draft score card from a quick sensei
pass. It stamps `win` whenever the whisper says a mill still looks open,
and it leaves trap/fort distinctions flat. Run it twice on a finished card
and the bytes stay identical — the printer resorts an already-complete
card rather than inventing a new one — but the draft itself is not the
authority. Use the sealed judge and the contest rules when the draft and
the fight disagree.
