Operator notes
==============

`/usr/local/bin/squidhealth` probes TCP reachability for roster peer
hosts. A ready print does not validate prefer tips, preference mode,
tip bind acceptance, peer journal revoke rows, ACL abort fold,
generation floors, or cutover receipts.

Durable peer hosts come from `/app/data/squid/` fixtures materialized
under `/var/lib/squid/peers/`. Roster order is `/etc/squid/roster.list`.
Surface materials under `/var/lib/squid/surface/` are used when
preference is not durable.
