# Contest rules

This booklet is a Santorini summit contest. First tries to climb onto a
level-3 building inside the sheet's turn budget. Second answers with ordinary
turns when the card asks for fighting play.

Workers move to an adjacent square at most one level higher than their start,
then usually build one level on an adjacent empty square (or place a dome on
a level-3 building). Domes block that square. First wins a line by stepping
onto level 3.

House notes for boards, floors, the table judge dialect, and the overnight
printer live beside this page under `/app/docs/`.
