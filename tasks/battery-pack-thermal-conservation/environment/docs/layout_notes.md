# Layout

- `/app/data/packs/` — pack thermal fixtures (ledger-protected)
- `/app/data/refs/` — frozen hotspot temperature references per profile
- `/app/data/policy/` — handoff accept receipt and fleet-trial preference material
- `/app/config/profiles/` — ship and fleet numerical release profiles
- `/app/solver/` — finite-volume thermal advance
- `/app/scripts/` — evaluation prep and graded report driver
