# Drop Snorkel task zips here

1. Download a task zip from **Snorkel Experts**.
2. Copy it into this folder (`tasks/inbox/`).
3. Tell Cursor: **"I added `my-task.zip` — run Step 0."**

The agent will unpack to `tasks/active/my-task/` and start the review.

Do not commit large zips if your team prefers — they are gitignored by default.
