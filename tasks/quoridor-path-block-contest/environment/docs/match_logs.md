# Match logs

Sample table sessions live under `/app/history/`. Each file is a short
recorded exchange with the sealed judge on a scratch position, kept so
newcomers can see the dialect the table speaks: how `view` prints path
lengths, how `probe` answers a wall try, and how `validate` reports each
step of a wall/pawn line.

These are demonstration games on throwaway boards, not the contest rounds.
Use them to learn the judge's replies, then read the real rounds under
`/app/puzzles/` yourself. The judge's path report — not any printer draft or
sensei whisper — is the authority on what actually happened on the board.
