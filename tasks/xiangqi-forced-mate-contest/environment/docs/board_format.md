# Round file layout

Each contest round lives at `/app/puzzles/board_NN.txt` and looks like:

```
round_id: 1
to_move: red
board:
....k....
....p....
.........
.........
....C....
.........
.........
.........
.........
....K....
```

- The grid is Xiangqi's 9×10 board. Uppercase pieces are Red; lowercase are
  Black; `.` is empty.
- Piece letters: `K` general, `A` advisor, `B` elephant, `N` horse, `R`
  chariot, `C` cannon, `P` soldier.
- The first board row is **rank 9** (Black's back rank); the last row is
  **rank 0** (Red's back rank). Files are `a`–`i` from the left. A square is
  named file then rank, e.g. `e9` is the Black general's usual seat and `e0`
  is Red's.
- Every round is Red to move.

Do not edit anything under `/app/puzzles/`. The table judge rereads the round
files on every call.
