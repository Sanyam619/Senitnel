📢 LATEST UPDATE
Network fields in task.toml have changed

Network access is now set per block — [environment] "public", [agent] "allowlist" with allowed_hosts, and [verifier] "no-network". Also remove network_mode = "none" from docker_compose.yaml if present.

Jul 31, 2026
Quality Check pass bar clarified. On coverage and faithfulness (scored 1–5), a task must land above 3 on both axes to pass — exactly 3 (or any single judge at 2 or below) sends it to needs-revision, and 2 or below is a hard fail. Don't ship borderline. Quality Check judge →
Jul 31, 2026
An eval failed with an infra error, or came back with blank feedback? A platform failure (Daytona/rate-limit errors, a one-off nonzero exit, "No evaluation information available") is not a task defect — don't mark the task Unfixable and don't burn a revision slot resubmitting blindly. Retry, and flag it with the UID if it persists. FAQ →
Jul 30, 2026
Linter rejects a task as "easy" after a difficulty downgrade? Known issue — don't hand-edit the task.toml pass-rate/difficulty fields to fight the linter. Flag it on Slack with the UID and the two conflicting values. FAQ →
